# Sistema 3 · Atelier modular

Diseño luminoso con tarjetas de usuarios, fondo lavanda y acento azul. `cliente-usestate/` usa estado local para cambiar de pantalla y `cliente-router/` usa React Router. Ambos se conectan a la API y base SQL compartidas de `../api/`.

La portada general, instalación y requisitos están en [el README de R3](../README.md).
