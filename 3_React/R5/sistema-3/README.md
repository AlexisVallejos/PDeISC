# Sistema 3 · Atelier modular

Diseño luminoso con tarjetas de usuarios, fondo lavanda y acento azul. `cliente-usestate/` usa estado local para cambiar de pantalla y `cliente-router/` usa React Router. `cliente-next/` (puerto 5189) es la versión en Next.js con piezas 3D de «arcilla» que se pueden tocar (React Three Fiber) y componentes de React Bits. Los tres se conectan a la API y base SQL compartidas de `../api/`.

La portada general, instalación y requisitos están en [el README de R5](../README.md).
